# Agent Workspace

A workspace for organizing reusable agent skills, instructions, and helper scripts for Codex and other AI coding agents.

## Contents

- `skills/markitdown/SKILL.md`: Skill instructions for using MarkItDown from Codex.
- `skills/markitdown/scripts/batch_markitdown.py`: Batch conversion helper that writes one Markdown file per input and records a JSON conversion report.
- `skills/markitdown/agents/openai.yaml`: Agent-facing metadata for the skill.

## Current Skills

### MarkItDown

Codex skill and batch helper for converting documents, folders, URLs, and mixed file collections to Markdown with Microsoft MarkItDown.
